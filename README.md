# las-auras

Historia de usuario:
Como persona que cuida plantas, quiero utilizar un sensor de humedad conectado a Arduino para conocer la humedad de la tierra y saber cuándo es necesario regar, para mantener mis plantas saludables y evitar desperdiciar agua.

2. Requerimientos funcionales:
Son las funciones que debe realizar el sistema.
1. Detectar la humedad: el sensor debe medir la humedad de la tierra.
2. Enviar información: el sensor debe enviar los datos al Arduino.
3. Interpretar los datos: Arduino debe procesar la información recibida.
4. Informar el estado: el sistema debe indicar si la tierra está seca o húmeda.
5. Activar una alerta: puede encender un LED para avisar cuando la tierra esté seca.
6. Controlar el riego: opcionalmente, puede activar una bomba de agua cuando la humedad sea baja.

3. Requerimientos no funcionales
Son las características de calidad que debe tener el sistema.
1. Facilidad de uso: debe ser sencillo de utilizar y comprender.
2. Precisión: debe proporcionar mediciones de humedad suficientemente confiables.
3. Rapidez: debe detectar y comunicar los cambios de humedad en poco tiempo.
4. Seguridad: los componentes eléctricos deben estar protegidos del agua.
5. Bajo costo: debe utilizar componentes económicos y accesibles.
6. Durabilidad: los componentes deben resistir el uso habitual y tener un mantenimiento adecuado.
